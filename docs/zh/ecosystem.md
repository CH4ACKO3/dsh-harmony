# 生态

当 DSH 官方扩展点无法覆盖某项修改时，独立插件可以使用 Harmony。这里沿用 [Awesome DSH Plugin](https://github.com/Deep-Space-Nine/awesome-dsh-plugin) 的分类词汇，但每个项目仍由各自仓库独立开发、发布和治理。

## 添加项目

目录通过 Pull Request 维护。编辑 [`docs/.vitepress/ecosystem.ts`](https://github.com/memorax-ai/dsh-harmony/edit/docs/docs/.vitepress/ecosystem.ts)，添加一条包含以下信息的事实性记录：

- 公开的源码仓库和已发布的软件包；
- 至少一个真实的 `dsh.harmony` Patch 声明；
- 一个来自 Awesome DSH Plugin 现有分类词汇的类别；
- 简短的中英文功能描述；
- 安装命令，以及实际作用的 Host 或 WebUI 目标。

请保持描述简短、可核验。被收录只代表更容易被发现，不表示 Harmony 维护者已经完成安全审查、兼容性保证、认证或背书。
